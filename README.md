# Portfólio de Luiza Sena

Portfólio pessoal publicado em https://luizasenacafe.github.io/ pelo GitHub Pages, a partir da raiz da branch `main`.

## Edição

- `index.html`: página de boas-vindas.
- `portfolio.html`: conteúdo, projetos, experiências, formação e links.
- `assets/site.css`: identidade visual (preto, prata e vermelho) e layout responsivo das duas páginas.
- `assets/site.js`: lanterna do cursor na boas-vindas, menu de celular, filtros de projetos, modo eclipse, cópia de e-mail e entrada das seções ao rolar.
- `assets/scene-wide.svg`, `assets/scene-tall.svg`, `assets/skyline.svg`: ilustrações animadas (eclipse, torres e brasas), feitas para este site.

Não é necessário instalar dependências ou executar uma compilação. Para visualizar localmente, use um servidor HTTP na raiz do repositório, por exemplo `python -m http.server 8765`.

O conteúdo profissional segue o currículo em `assets/curriculo-luiza-sena.pdf`. Datas previstas de conclusão devem ser revisadas quando houver mudanças.

As fontes (Pirata One, Oswald, Cormorant Garamond e JetBrains Mono) são carregadas pelo Google Fonts, com alternativas locais. As ilustrações dos cartões de projeto são composições decorativas em CSS, não capturas das aplicações.

Os arquivos `index-*.js`, `index-*.css`, `city-bg-*.jpg`, `luiza-avatar-*.jpeg` e os GIFs em `assets/` são de versões anteriores e não são mais usados pelo site.
