# Portfólio de Luiza Sena

Portfólio pessoal publicado em https://luizasenacafe.github.io/ pelo GitHub Pages, a partir da raiz da branch `main`.

## Edição

- `index.html`: conteúdo, projetos, experiências, formação e links.
- `assets/portfolio.css`: identidade visual e layout responsivo.
- `assets/portfolio.js`: menu de celular, filtros de projetos, controle de animações e cópia de e-mail.

Não é necessário instalar dependências ou executar uma compilação. Para visualizar localmente, use um servidor HTTP na raiz do repositório, por exemplo `python -m http.server 8765`.

O conteúdo profissional foi atualizado com base no currículo fornecido em setembro de 2026. O e-mail de contato segue esse currículo. Datas previstas de conclusão devem ser revisadas quando houver mudanças.

As fontes são carregadas pelo Google Fonts, com alternativas locais. Os GIFs estão no repositório; o arcade usa a imagem publicada no repositório de perfil. Os créditos visuais estão no rodapé do site. As ilustrações dos cartões de projeto são composições decorativas em CSS, não capturas das aplicações.

Os arquivos antigos com nomes `index-*.js` e `index-*.css` foram preservados, mas não são mais usados pelo site.
